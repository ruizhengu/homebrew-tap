# ruizhengu's Homebrew tap

Personal Homebrew formulas. One tap, one install line per tool:

```bash
brew install ruizhengu/tap/kiwi-dl
```

## [kiwi-dl](https://github.com/ruizhengu/kiwi-dl)

Download public MEGA links from your terminal: resumable, verified,
quota-aware. Upgrades and removal go through brew: `brew upgrade kiwi-dl`,
`brew uninstall kiwi-dl`.
